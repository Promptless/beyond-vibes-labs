# Beyond Vibes AI Labs

Hands-on sessions where you test your own AI agent setup on a real documentation task and score the result against a maintainer-validated rubric. "It looks good" becomes a number you can explain.

Every task comes from [DoGBench](https://dogbench.ai), Promptless's benchmark of documentation work drawn from real pull requests in open-source projects. You bring the agent you use every day, with your own instructions, skills, and model. The lab supplies the task, the rubric, and the sheets for scoring and tagging.

Hosted by [Promptless](https://promptless.ai).
