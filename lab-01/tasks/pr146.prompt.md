Title: feat: refactor setConfig to accept object params and support multi-value input
Description: The `setConfig` function signature changes from positional arguments to a single destructured object parameter `{ configPath, args }`. Config file reading, including error handling, is now performed inside `setConfig` rather than at the call site; if the config file cannot be read, the function returns `null`.

The `--input` argument now supports comma-separated values. When multiple paths are provided, they are split into an array and each entry is resolved to an absolute path via `path.resolve`. Entries beginning with ` or ` are left unmodified. The resulting `config.input` value is always an array.

Tests are updated to assert the new array shape for `input` and include a new case covering multiple comma-separated input values. The dependency on the shared common library is bumped to the latest patch release.
